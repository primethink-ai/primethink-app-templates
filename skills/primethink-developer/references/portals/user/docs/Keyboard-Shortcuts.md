# Keyboard Shortcuts

PrimeThink provides keyboard shortcuts for quick navigation and common actions. Use these shortcuts to work more efficiently without reaching for your mouse.

---

## Viewing Shortcuts in the App

Press `⌘ /` (Mac) or `⌃ /` (Windows/Linux) at any time to open the **App Keyboard Shortcuts** window, which shows all available shortcuts.

---

## Core Actions

| Shortcut | Description |
|----------|-------------|
| `⌥ ⌃ C` | New Chat |
| `⌥ ⌃ /` | New Temp Chat |
| `⌥ ⌃ W` | New Workspace |
| `⌥ ⌃ T` | New Task |

---

## Workspaces Navigation

| Shortcut | Description |
|----------|-------------|
| `⌥ [` | Previous Workspace |
| `⌥ ]` | Next Workspace |

---

---

## Group Switching

Hold `⌘` (Mac) or `⌃` (Windows/Linux) to reveal a group switcher overlay in the sidebar. Each group is shown with its name and a number badge. While holding the key, press the number to switch to that group.

| Shortcut | Description |
|----------|-------------|
| Hold `⌘` / `⌃` | Show group switcher overlay with numbered badges |
| `⌘ 1` – `⌘ 9` | Switch to group 1–9 (Mac) |
| `⌃ 1` – `⌃ 9` | Switch to group 1–9 (Windows/Linux) |
