# Support

## Contact Support

For any issue or question, contact the support team at [support@primethink.ai](mailto:support@primethink.ai).

When reporting a problem, include:

- What you were trying to do, and what happened instead
- The group and chat where it occurred (a link is ideal)
- Any error message shown
- Screenshots, if the issue is visual

## Community Forum

Join the [community forum](https://community.primethink.ai) to ask questions, share what you've built, and learn from other PrimeThink users.

## Feature Requests

Have an idea that would make PrimeThink better? Post it on the [community forum](https://community.primethink.ai) or send it to [support@primethink.ai](mailto:support@primethink.ai) — real-world use cases help prioritise the roadmap.

## Documentation

If you couldn't find what you were looking for in these docs, tell us that too — gaps in the documentation are bugs like any other.
